## ✨ [ KEY_FEATURES ]

* **Immersive Interface:** A tactical/cyberpunk design featuring grid systems, glitch effects, and technical typography.
* **Responsive Layout:**
    * **Desktop:** Full-width layout with complex grid structures and hover interactions.
    * **Mobile:** Optimized stacked layout with glass-morphism panels for readability.
* **Interactive Elements:** Custom cursor followers, parallax mouse movement effects, and smooth scroll transitions.
* **Visual Database:** A "Bento-style" gallery grid to showcase character designs and illustrations.
* **Experience Timeline:** A structured visualization of my academic and professional journey.

## 📂 [ LOCAL_INITIALIZATION ]

Follow these steps to deploy this protocol on your local machine:

1.  **Clone Repository**
    ```bash
    git clone [https://github.com/mirae-devlog/Mirae-Website.git](https://github.com/mirae-devlog/Mirae-Website.git)
    cd Mirae-Website
    ```

2.  **Install Dependencies**
    ```bash
    pnpm install
    # or if using npm:
    # npm install
    ```

3.  **Run Development Server**
    ```bash
    pnpm dev
    # or:
    # npm run dev
    ```

4.  **Access Localhost**
    Open your browser and navigate to `http://localhost:3000`.
